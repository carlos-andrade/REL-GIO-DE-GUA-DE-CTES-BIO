# D0 — LOG DE CORREÇÕES E REVISÕES V1

## Finalidade
Registrar qualquer correção feita após uma coleta, preservando a versão anterior da informação.

## Regra fundamental
Dados brutos originais não devem ser apagados para ocultar uma correção.

## Registro
| correção_id | data/hora | arquivo | ID afetado | valor/estado anterior | novo valor/estado | motivo | responsável | evidência |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

## Tipos de correção
- erro de digitação;
- unidade incorreta;
- identificação incorreta;
- classificação de status;
- correção documental;
- outro, com justificativa.

## Proibição
Não usar este log para fabricar ou substituir uma medição física que não ocorreu.
