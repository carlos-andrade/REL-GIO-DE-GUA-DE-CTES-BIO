# D0 — ORÇAMENTO DE INCERTEZA S001 V1

## Finalidade
Definir antecipadamente as fontes de incerteza que deverão ser avaliadas após a coleta física.

## Grandezas
- Dimensões lineares
- Área/geométrica A(H)
- Volume V
- Nível H
- Volume por incremento ΔV
- Relação H↔V
- Volume de descarga
- Volume residual

## Componentes Tipo A
A determinar a partir das repetições experimentais:
- dispersão das medições;
- repetibilidade do método;
- repetibilidade entre leituras.

Para n observações:
uA = s / √n

## Componentes Tipo B
Avaliar conforme evidência disponível:
- resolução do instrumento;
- especificação de exatidão;
- certificado/calibração;
- método de leitura;
- temperatura;
- efeitos geométricos;
- menisco, quando aplicável;
- posicionamento;
- outros efeitos identificados.

## Combinação
Quando aplicável:

u_c = √(uA² + uB1² + uB2² + ...)

A fórmula e os componentes efetivamente usados deverão ser registados com as respetivas hipóteses.

## Regra
Nenhum componente recebe valor numérico antes de existir evidência correspondente.

PENDENTE DE DADOS EXPERIMENTAIS.
