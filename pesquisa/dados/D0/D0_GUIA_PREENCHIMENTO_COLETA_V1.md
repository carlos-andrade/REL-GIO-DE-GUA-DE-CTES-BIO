# D0 — GUIA DE PREENCHIMENTO DA COLETA V1

## Objetivo
Padronizar o preenchimento dos registros D0-P01 e D0-P02 durante a coleta física.

## Ordem obrigatória
1. Abrir uma sessão em D0_REGISTRO_SESSAO_MEDICAO_V1.md.
2. Identificar protótipo, configuração, instrumentos e condições ambientais.
3. Registrar cada observação no arquivo bruto.
4. Usar um novo ID para cada observação.
5. Registrar repetições separadamente.
6. Registrar anomalias no momento em que ocorrerem.
7. Encerrar a sessão somente após conferir a rastreabilidade.

## Regras de preenchimento
- Não arredondar além da resolução efetiva do instrumento.
- Não substituir valor ausente por zero.
- Não substituir uma medição impossível por estimativa.
- Não apagar uma observação rejeitada; registrar o motivo.
- Não alterar retroativamente dados brutos sem deixar registro de correção.
- Data e hora devem ser registradas de forma rastreável.
- Temperatura deve ser registrada quando puder afetar a medição.

## Identificação das medições
Use a grandeza efetivamente medida, por exemplo:
- altura;
- diâmetro;
- largura;
- comprimento;
- volume adicionado;
- altura correspondente ao volume;
- volume residual;
- volume descarregado.

## Situações especiais
Se ocorrer vazamento, bolha, transbordamento, leitura instável, deslocamento do instrumento ou outra anomalia:
1. preserve a observação;
2. descreva o evento;
3. marque o status apropriado;
4. não corrija silenciosamente o valor.

## Critério de encerramento da coleta
A coleta somente pode ser considerada concluída quando:
- todos os pontos planejados foram registrados;
- as repetições críticas estão presentes;
- os instrumentos estão identificados;
- as anomalias foram documentadas;
- os arquivos foram preservados.
