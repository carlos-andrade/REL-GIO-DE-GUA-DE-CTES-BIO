# CHECKLIST PRÉ-COLETA FINAL — D0

## Regra

Este checklist confirma somente a prontidão para executar a medição. Não
constitui evidência de que a medição ocorreu.

## A. Governança
- [ ] Repositório correto confirmado.
- [ ] Caminho D0 confirmado.
- [ ] Configuração do protótipo identificada.
- [ ] Procedimentos P01/P02 disponíveis.
- [ ] Sessão D0-S### definida.

## B. Instrumentação
- [ ] Instrumento de medição dimensional identificado.
- [ ] Instrumento de volume identificado.
- [ ] Instrumento de temperatura identificado, quando aplicável.
- [ ] Resolução registrada.
- [ ] Faixa registrada.
- [ ] Situação de calibração registrada.
- [ ] Instrumento_ID preenchido.

## C. Protótipo
- [ ] Reservatório identificado.
- [ ] Referências geométricas definidas.
- [ ] Pontos de medição H definidos.
- [ ] Método de medição V definido.
- [ ] Condição inicial registrada.

## D. Dados
- [ ] CSV bruto preservado.
- [ ] IDs únicos preparados.
- [ ] Repetições separadas.
- [ ] Data/hora preparada.
- [ ] Temperatura preparada.
- [ ] Observações/anomalias preparadas.
- [ ] Nenhum valor físico inventado ou pré-preenchido.

## E. Execução
- [ ] P01 executado.
- [ ] P02 executado.
- [ ] Repetições realizadas.
- [ ] Anomalias registradas.
- [ ] Sessão encerrada formalmente.

## F. Pós-coleta
- [ ] Validador automático executado.
- [ ] Resultado preservado.
- [ ] Hash calculado, quando a versão for formalizada.
- [ ] Processamento executado separadamente.
- [ ] Revisão D0 iniciada.
