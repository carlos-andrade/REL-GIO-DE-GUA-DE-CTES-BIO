# D0 — Checklist de Execução V1

**Projeto:** Relógio de Água de Ctesíbio  
**Repositório:** carlos-andrade/RELOGIO_DE_AGUA_DE_CTESIBIO  
**Fase:** D0 — Geometria e volume de referência

## Pré-execução
- [ ] Protótipo/peça física identificada.
- [ ] Reservatório identificado.
- [ ] Instrumentos identificados.
- [ ] Resolução e incerteza dos instrumentos registradas.
- [ ] Condições ambientais registradas.
- [ ] Conjunto nivelado.
- [ ] Procedimento D0-P01 disponível.
- [ ] Procedimento D0-P02 disponível.

## Aquisição
- [ ] Dimensões críticas medidas ≥ 3 vezes.
- [ ] Valores brutos registrados.
- [ ] Níveis H definidos.
- [ ] Volumes V associados aos níveis H.
- [ ] Volume de descarga medido.
- [ ] Volume residual medido.
- [ ] Anomalias registradas.
- [ ] Fotografias associadas aos IDs.

## Processamento
- [ ] Média calculada.
- [ ] Dispersão calculada.
- [ ] Incerteza Tipo A estimada quando aplicável.
- [ ] Incerteza Tipo B identificada quando aplicável.
- [ ] Incerteza combinada calculada quando aplicável.
- [ ] Relação H↔V construída.
- [ ] Consistência dimensional revisada.

## Liberação
- [ ] Dados brutos preservados.
- [ ] Dados processados separados dos brutos.
- [ ] Auditoria de rastreabilidade concluída.
- [ ] Critérios de aceitação atendidos.
- [ ] Relatório D0 atualizado.
- [ ] D0 marcada como CONCLUÍDA somente após revisão.

**Regra:** checklist não preenchido não constitui evidência de execução.
