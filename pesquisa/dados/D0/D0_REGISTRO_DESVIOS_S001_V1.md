# REGISTRO DE DESVIOS — D0-S001

## Finalidade

Registrar qualquer diferença entre o procedimento planejado e a execução real,
preservando o contexto necessário para avaliar o impacto sobre os dados.

## Regra fundamental

Um desvio não deve ser ocultado, apagado ou corrigido silenciosamente.

A existência de um desvio não implica automaticamente rejeição dos dados.
O impacto deverá ser analisado.

## Classificação

- **D1 — documental:** afeta somente documentação.
- **D2 — operacional:** altera o procedimento, mas pode ser rastreado.
- **D3 — metrológico:** pode alterar o resultado ou a incerteza.
- **D4 — integridade:** compromete a rastreabilidade dos dados.
- **D5 — segurança:** exige interrupção ou condição segura.

## Avaliação

Para cada desvio relevante registrar:

1. o que ocorreu;
2. quando ocorreu;
3. quais observações foram afetadas;
4. qual instrumento/configuração estava em uso;
5. se houve correção;
6. se a correção foi documentada;
7. se os dados permanecem utilizáveis;
8. se é necessária repetição.

## Regra de repetição

Quando um desvio comprometer a validade de uma observação, a observação
original permanece preservada e uma nova observação deverá receber novo ID.

Nunca substituir a observação anterior pela nova.
