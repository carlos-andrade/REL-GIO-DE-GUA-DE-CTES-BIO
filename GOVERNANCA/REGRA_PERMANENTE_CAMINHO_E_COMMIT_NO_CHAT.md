# REGRA PERMANENTE — CAMINHO E COMMIT NO CHAT

**Projeto:** RELÓGIO DE ÁGUA DE CTESÍBIO
**Repositório oficial:** carlos-andrade/RELOGIO_DE_AGUA_DE_CTESIBIO
**Carta superior:** GOVERNANCA/CARTA_REGENTE_DO_PROJETO_V1.md

## Regra

Toda confirmação de trabalho realizado no repositório deve informar no próprio chat:

1. repositório;
2. caminho completo do arquivo ou arquivos;
3. commit SHA;
4. status da operação.

## Operação obrigatória

O conteúdo substantivo permanece no GitHub. O chat publica a confirmação operacional necessária para rastreabilidade imediata.

## Regra de integridade

Não informar caminho, commit ou status por inferência. A confirmação deve ocorrer somente após a operação no GitHub ter sido concluída.

## Princípio

**Produzir → salvar no GitHub → informar caminho → informar commit → confirmar no chat.**
