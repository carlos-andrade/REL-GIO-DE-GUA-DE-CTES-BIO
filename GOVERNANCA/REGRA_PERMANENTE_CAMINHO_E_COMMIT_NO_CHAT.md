# Regra Permanente — Caminho e Commit no Chat

## Regra
Toda confirmação de trabalho realizado no repositório deve informar no próprio chat, de forma explícita:

1. **Repositório**
2. **Caminho completo do arquivo ou arquivos criados/alterados**
3. **Commit SHA**

Esta regra complementa as regras anteriores de GitHub-first e de respostas lidas no Git.

## Operação obrigatória
O conteúdo substantivo permanece no GitHub. O chat deve publicar somente a confirmação operacional, incluindo caminho e commit, para permitir rastreabilidade imediata sem reproduzir o conteúdo integral do artefato.

## Princípio
**Produzir → salvar no GitHub → informar caminho → informar commit → confirmar no chat.**
