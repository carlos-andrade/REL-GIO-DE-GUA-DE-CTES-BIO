# REGRA PERMANENTE — GITHUB PRIMEIRO

**Projeto:** RELÓGIO DE ÁGUA DE CTESÍBIO  
**Data:** 27/09/2026  
**Status:** REGRA OPERACIONAL PERMANENTE

## Regra

Todo conteúdo produzido durante os chats deste projeto deve ser salvo no repositório GitHub do projeto, na pasta correspondente ao seu tipo e finalidade.

O GitHub é a **fonte de verdade documental** do projeto.

O chat deve ser utilizado somente para:

- decisões;
- instruções;
- execução;
- status;
- confirmações;
- referências objetivas.

Artefatos completos produzidos para o projeto não devem ser reproduzidos integralmente no chat quando já tiverem sido salvos no repositório.

## Obrigação de registro

Sempre que um conteúdo for criado ou alterado, registrar:

1. repositório;
2. pasta;
3. nome do arquivo;
4. commit realizado.

## Regra de continuidade

Esta regra deve ser aplicada aos próximos chats do projeto, preservando a organização documental e evitando que o conteúdo do projeto fique exclusivamente armazenado no histórico da conversa.

**Princípio:** produzir → salvar no GitHub → confirmar no chat.
