# REGRA PERMANENTE — RESPOSTAS LIDAS NO GIT

**Projeto:** RELÓGIO DE ÁGUA DE CTESÍBIO  
**Data:** 27/09/2026  
**Status:** REGRA OPERACIONAL PERMANENTE

## Regra

As respostas substantivas e os artefatos produzidos para este projeto devem ser estruturados para leitura diretamente no GitHub.

O chat não é o destino principal do conteúdo documental.

Quando uma resposta representar documentação, especificação, decisão, arquitetura, análise, roteiro, instrução, regra, projeto ou outro artefato do projeto:

1. criar ou atualizar o arquivo correspondente no repositório;
2. organizar o conteúdo em Markdown legível no GitHub;
3. registrar o conteúdo completo no arquivo;
4. confirmar no chat somente o local e o commit.

## Princípio

**A resposta pertence ao repositório. O chat apenas confirma a operação.**

## Exceções

Perguntas operacionais simples, confirmações e decisões que não constituam artefatos documentais podem ser respondidas diretamente no chat.

Esta regra complementa a regra permanente GITHUB PRIMEIRO.
