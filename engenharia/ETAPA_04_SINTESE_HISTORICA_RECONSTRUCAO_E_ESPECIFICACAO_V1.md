# ETAPA 04 — SÍNTESE HISTÓRICA, RECONSTRUÇÃO E ESPECIFICAÇÃO

**Projeto:** RELÓGIO DE ÁGUA DE CTESÍBIO  
**Repositório:** carlos-andrade/REL-GIO-DE-GUA-DE-CTES-BIO  
**Versão:** V1  
**Data:** 27/09/2026

## 1. Objetivo

Converter as evidências validadas em uma especificação coerente para o desenvolvimento de engenharia, mantendo separadas as afirmações históricas, as interpretações e as soluções modernas.

## 2. Documento central existente

A especificação desta etapa está registrada em:

`pesquisa/sintese/ESPECIFICACAO_SINTESE_TECNICA_V1.md`

com apoio de:

- `pesquisa/sintese/README.md`;
- resultados de `pesquisa/validacao/`;
- evidências organizadas em `pesquisa/`.

## 3. Camadas obrigatórias

### HISTÓRICA

O que as fontes permitem afirmar.

### RECONSTRUTIVA

Interpretações necessárias para representar um mecanismo funcional quando os detalhes não são determinados diretamente.

### PROJETUAL

Soluções modernas escolhidas para produzir, medir, controlar, testar e auditar o protótipo.

## 4. Fluxo de especificação

```text
FONTE → EVIDÊNCIA → AFIRMAÇÃO → INTERPRETAÇÃO → RECONSTRUÇÃO → REQUISITO → SOLUÇÃO DE ENGENHARIA
```

## 5. Requisitos de entrada para a Etapa 05

A síntese deverá fornecer ao modelo matemático e protótipo:

- variáveis críticas;
- funções hidráulicas;
- cadeia de medição;
- condições de estabilidade;
- ciclo automático pretendido;
- necessidades de compensação temporal;
- critérios de precisão;
- incertezas conhecidas;
- hipóteses que precisam ser testadas.

## 6. Critério de conclusão

A etapa estará concluída quando cada requisito crítico puder ser relacionado à evidência, interpretação ou decisão de engenharia correspondente.

## 7. Transição

A Etapa 05 inicia o modelo matemático e o protótipo experimental com base nesta especificação.
